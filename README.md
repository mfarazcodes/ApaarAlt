# APAAR Bridge (ApaarAlt)

A privacy-first verification layer between college ERPs, AICTE, NAD/ABC, students and employers, for SIH 2026.

The app is in [`apaar-platform/`](apaar-platform/). Start with [`apaar-platform/README.md`](apaar-platform/README.md) for setup, roles, settings, architecture and a five-minute demo script, and [`CHANGELOG.md`](CHANGELOG.md) for what changed and what is still open.

```bash
cd apaar-platform
npm install
npm run dev     # http://localhost:3000/login
```

All people, colleges and ID numbers in the demo are fictional.
